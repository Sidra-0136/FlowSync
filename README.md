FlowSync 💜

✨ Simplify. Organize. Flow.

FlowSync is a modern and responsive SaaS landing page designed to showcase a productivity platform with a clean UI, smooth interactions, and a user-friendly experience.

🚀 Features

- 🌙 Light & Dark Mode
- 📱 Fully Responsive Design
- 📋 Interactive FAQ Accordion
- 📝 Contact Form Validation
- 🎬 Demo Modal
- 📱 Mobile Navigation
- 🔗 Smooth Scrolling
- ✨ Button Animations
- ♿ Accessibility Support

🛠️ Technologies

HTML5 • CSS3 • JavaScript • Git & GitHub

🎯 What I Built

A complete responsive SaaS landing page with multiple sections, interactive components, form validation, theme switching, and mobile-friendly navigation.

💡 Challenges & Solutions

One of the main challenges was making all sections responsive while keeping the design consistent. I solved this using CSS media queries, Flexbox, Grid, and JavaScript DOM manipulation. Implementing dark mode, FAQ interactions, form validation, and the demo modal also helped me strengthen my JavaScript skills.
